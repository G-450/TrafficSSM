# AI-agent context package

This folder is the durable starting context for an AI agent working in this repository. Read files in this order:

1. `PROJECT_CONTEXT.md`
2. `CURRENT_FOCUS.md`
3. `OPERATING_RULES.md`
4. the linked canonical document(s) in `docs/`

Do not use this compact context as permission to invent requirements. It summarizes, while `docs/` is authoritative. Update it in the same PR whenever the project state, active work, or binding decisions change.
