### ✅ Phase 6 — Spatial-temporal encoder (`src/st_dssm/encoder.py`)

Architecture (ADR-0007):
- `CausalGatedTemporalConv` — strict causal left-padding, no future leakage
- `SpatialTemporalBlock` — Gated TCN → ChebConv (K=3) → Gated TCN → LayerNorm → Dropout → Residual
- `SpatialTemporalEncoder` — 2 blocks, output `[B, L, N, 64]`, `get_context_summary` → `[B, N, 64]`
- Graph: `ChebConv`, `calculate_normalized_laplacian`, `calculate_scaled_laplacian`,
  `compute_chebyshev_polynomials`, symmetrization `(W + W.T)/2` per ADR-0009
- 104,320 trainable parameters

Tests (14): causality probe, node-permutation equivariance, overfit, gradient flow,
CLI smoke, shape contract, non-finite guard.

**Gate:** Shape, gradient, and overfit-one-batch tests pass. ✅

---

### ✅ Phase 7 — Probabilistic forecast head (`src/st_dssm/forecast_head.py`)

Architecture (ADR-0007):
- `GaussianForecastHead` — autoregressive 12-step decoder
- Learned horizon position embeddings `[H, hidden_dim]`
- MLP: `concat[z, context_summary, horizon_embed, prev_mu]` → `(mu_raw, log_sigma_raw)`
- `sigma = softplus(clamp(log_sigma_raw, -8, 5)) + 1e-4` — strictly positive, bounded
- Stochastic teacher forcing: `teacher_force_ratio` in [0,1]; 0.0 at val/test
- `sample_prediction` — reparameterization trick

Tests (25): output shapes, sigma positivity, log-sigma clamp boundary, teacher forcing
vs. autoregressive, gradient flow, single-batch overfit, sampling distribution mean,
all input validation paths.

**Gate:** Finite-loss and sigma-positivity tests pass. ✅

### ✅ Phase 8 — DSSM integration (`src/st_dssm/dssm.py`)

Architecture (ADR-0007):
- `GaussianDSSM` — wraps Phase 6 encoder + Phase 7 forecast head
- `_TransitionNet` — causal GRU prior `p(z_t | z_{t-1}, c_t)`, node-wise shared weights
- `_RecognitionNet` — bidirectional GRU posterior `q(z_t | context_{1:L}, x, m)`,
  training only; zeroes out unobserved speed before recognition
- Latent: 32-dim diagonal Gaussian per sensor node
- ELBO = `recon_nll + beta * KL(q||p)` — components returned separately
- `beta` schedule: 0→1 over first 20 epochs (caller-managed)
- Teacher forcing: 1.0→0.0 over first 50% of max epochs (caller-managed)
- `forward_train(x, cheb, y, obs_mask_hist, obs_mask_fore, teacher_force_ratio, beta)`
- `forward_predict(x, cheb)` — prior only, targets never accessed
- Hard `ValueError` on non-finite ELBO
- `get_capacity_report()` — per-component parameter counts

Helpers in `dssm.py`:
- `_diagonal_gaussian_kl(mu_q, sigma_q, mu_p, sigma_p)` — closed-form scalar KL ≥ 0
- `_masked_gaussian_nll(y, mu, sigma, mask)` — masked NLL over observed targets

CLI: `st-dssm-dssm --synthetic-smoke` — runs `forward_train` + backward +
`forward_predict` on synthetic data, verifies shapes, sigma positivity, KL ≥ 0,
gradient flow, and reports capacity.

Tests (30): shapes, sigma positivity, KL non-negative, ELBO finite, gradient flow,
beta=0 behaviour, single-batch ELBO decrease, prior≠posterior, all validation paths,
capacity report, CLI.

**Gate:** End-to-end learning on a small fixture confirmed. ✅
